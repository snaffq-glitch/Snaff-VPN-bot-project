# 🛡 Snaff VPN — VPN-бот для Telegram

Продажа личного VPN прямо в Telegram. Бот принимает платежи в Stars и автоматически выдаёт ключи Snaff. (Название изменено)

## 🚀 Возможности
- 3 тарифа: день / неделя / месяц
- Автоматическая генерация конфигов Snaff (Название изменено)
- QR-код для быстрого подключения
- Оплата через Telegram Stars

## 🛠 Технологии
- Python 3.10+
- aiogram 3.x
- WireGuard + wg-easy
- Docker

## 📦 Установка
1. Клонируй репозиторий
2. `pip install -r requirements.txt`
3. Создай `.env` с токеном бота и URL API
4. `python bot.py`

## ⚠️ Дисклеймер
Сервис для защиты данных. Использование в противоречии с законодательством запрещено.
